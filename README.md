# Senior Analyst to Lead / Architect Career Accelerator 🚀

A structured, interactive 22-week career progression roadmap and competency development web application designed for Senior Analysts transitioning into Lead, SME, and Associate Architect roles.

## 🌐 Live Web App (PWA)
**Live on GitHub Pages:** [https://codebase-lab-cloud.github.io/upskilling/](https://codebase-lab-cloud.github.io/upskilling/)

---

## ✨ Features

- **22-Week Structured Sprint Roadmap**:
  - **Phase 1 · Consulting Foundations (Wk 1-4)**: MECE principle, Pyramid Principle executive communication, hypothesis matrices, profitability & market entry case frameworks.
  - **Phase 2 · Data Foundations & BI (Wk 5-10)**: Advanced SQL (Window functions, CTEs, optimization), Advanced Excel (Power Query, dynamic arrays), BI Data Modeling (Star schemas, DAX time intelligence / Tableau LOD), Cohort retention decay analysis.
  - **Phase 3 · Statistics & Python (Wk 11-16)**: Descriptive statistics, Welch's t-tests, Chi-square tests, A/B test design & power calculations, RFM segmentation, and production-grade Pandas/Seaborn pipelines.
  - **Phase 4 · Advanced Analytics & Capstone (Wk 17-22)**: OLS regression diagnostics, time series forecasting, ML classification & clustering, executive data storytelling, end-to-end consulting capstone project, and portfolio/STAR interview prep.
- **Dynamic Task Extensibility**: Add custom tasks/deliverables to any week, or add entirely new custom modules and specialized learning tracks.
- **Clean Vector SVG Design**: Professional inline SVG icons throughout navigation, pillars, cards, and HUD (zero emojis).
- **True OLED Dark Mode & Crisp Light Theme**: Pitch black `#000000` dark mode and high-contrast light mode with one-click toggling and auto-persistence.
- **Mobile Responsive (iPhone 15 Optimized)**: Safe-area insets (`env(safe-area-inset-top)`, `env(safe-area-inset-bottom)`), thumb-friendly navigation bar, touch targets $\ge 44\text{px}$, and responsive slide-up modal sheets.
- **PWA Ready**: Web App Manifest (`manifest.json`), Apple touch icons, and standalone home screen installability on iOS and Android.
- **MECE Issue Tree & SCQA Canvas**: Interactive consulting hypothesis builder with preloaded templates for Profitability and Churn cases.
- **Strategic Competency Mind Map**: 6 core capability domains with 4-level mastery tracking (`Novice` $\rightarrow$ `Competent` $\rightarrow$ `Practitioner` $\rightarrow$ `SME / Lead`).
- **Deep Work Focus Timer**: 25-minute Pomodoro focus timer with sprint counter and hourly logging.
- **Zero Local Footprint**: 100% client-side with persistent `localStorage` and JSON backup/restore.
